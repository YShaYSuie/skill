# 实现经验（防复发，修改 build_docx.py 前必读）

以下条目来自真实缺陷案例（v2.3/v2.4 升级与回归期间发现并修复），改动 `scripts/build_docx.py` 时必须遵守；每条都对应一个已修复的回归点。

## 表格单元格编号解析

- 编号前缀正则含 `[、.．]` 时会匹配 IPv4（`10.50.10.`）与版本号（`2.`），截断后**静默丢数据**（实测 `10.50.10.22` → `22`）。
- 必须同时做两层防护：分隔符后负向断言 `(?!\d)` + **不变式校验**（prefix 之后的剩余文本去首尾空白必须等于 body，且 body 非空），校验失败返回 None 保留原文。
- 回归用例：`10.50.10.22` / `192.168.1.1` / `2.0系统升级方案` / `3.14 是圆周率` 不拆；`1. 第一项` / `一、总则` / `（一）条款` / `1、要点` 正常拆。

## 行内 token 化

- **禁止用 `match.lastgroup`** 判定命中的分支：最外层捕获组总是最后参与匹配，`lastgroup` 会返回 None，导致标记内容静默丢失（实测 `**打字 + 回车**` 的内容整体消失）。必须逐一检查具名组取第一个非 None 者。
- 行内标记可跨行（多行 `<font>` 块）：必须**先 token 化、再按 `\n`/`<br>` 切分**插入 `<w:br/>`，切分顺序颠倒会导致跨行标记漏配。
- 代码块渲染必须用开关（`inline_parsing_enabled = False`）跳过行内解析，否则命令中的 `*`、`` ` `` 被误处理。

## 中文标点规范化

- 规范化必须挂在 **parse_markdown 的全部 flush 入口**：paragraph、quote、table cell、list item、heading 五处缺一不可。只挂部分入口会产生「同类内容不同形态」混排（实测列表项/标题里的直引号漏转，用户一眼可见）。
- 引号必须**一次性成对输出**（左引号+内容+右引号），只输出引号本身会吞掉右引号（实测 4 左 0 右）。
- 路径/URL/命令保护（`PATH_LIKE_RE`）：包裹内容含盘符、反斜杠、`//`、URL scheme、常见文件扩展名时不转换。
- 语境判定用「引号外侧最近的非空白字符」而非紧邻字符（`输入 "yes" 后回车` 的紧邻字符是空格，外侧非空白才是中文）。

## 引号渲染形态（歧义宽度字符）

- `“”` 是 Unicode East Asian Ambiguous 字符：西文字体渲染为窄引号，中文字体渲染为全角宽引号。纯程序生成的 docx 若不写语言标记，Word 按西文渲染，与手动输入的形态不一致（本模板 Normal 走 Calibri，主题 ea 字体为空）。
- 含 CJK 的 run 必须显式写入 `<w:rFonts hint="eastAsia"/>` + `<w:lang w:val="zh-CN" w:eastAsia="zh-CN"/>`。
- **分支顺序坑**：`make_text_runs` 传入的 token 字典永远非空（至少含 text 键），`if fmt: ... elif CJK: ...` 会导致语言标记分支永不执行（实测 hint 0 处）。正确做法：先应用格式、再统一追加语言标记（复用已有 rPr，rFonts 插到 rPr 首位保证 OOXML 元素顺序合法）。

## 引用块与空行

- 源文件引用块结尾的「空引用行」（仅 `>`）是 Markdown 块边界标记，不是内容；拼进文本会产生段尾 `<w:br/>` 空行。`flush_quote` 必须去首尾空行、压缩连续空行（保留单个中间空行）。
- 诊断「空行」类问题看三层，全部查完再下结论：① body 顶层空段落 ② 段内 `<w:br/>` ③ 模板样式段间距。

## 模板感知与水平线

- 视觉样式一律由模板承载，程序不得硬编码。水平线（hr）只有模板定义了 `Horizontal Line` / `HR` / `Horizontal Rule` / `水平线` / `分隔线` 样式才渲染，否则跳过。
- 新增能力时先问「显隐/样式归模板还是归程序」，归模板的必须留模板挂点。

## 验证纪律

- 每次修改后必须做**全量回归**（IP 完整、无行内标记残留、无 `---` 文本、弯引号配对、代码块原样、末尾空行为零），不能只测新改的点。
- XML 级验收直接查 document.xml 的标签计数（`<w:b`、`<w:br/>`、`w:pBdr`、`w:hint="eastAsia"`），不能只信转换脚本的 JSON 报告——报告自身也可能有 bug。
- 输出文件被占用（预览器锁定）时换文件名生成，不要静默失败。
