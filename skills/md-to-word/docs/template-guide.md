# Word 模板指南

## 默认模板

- 文件名必须是 `default.docx`。
- 路径是 `templates/default.docx`。
- 只允许存在一个默认模板。

## 模板库

- 可选目录：`templates/library/`。
- 文件名用用途命名，例如 `产品需求.docx`、`项目方案.docx`。
- 不要把临时上传的 Word 自动保存进模板库。

## 模板应包含

建议模板至少准备：

- 标题样式或等价样式。
- 一至四级标题样式。
- 正文样式。
- 表格样式。
- 页眉、页脚、页码。
- 章节自动编号或多级列表。

## 更换默认模板

1. 提供新 Word 模板。
2. 让 Skill 检查 Heading、正文、编号体系。
3. 确认后替换 `templates/default.docx`。
