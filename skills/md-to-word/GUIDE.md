# md-to-word 使用指南

把 Markdown 或已有 Word 文档整理成符合指定 Word 模板的正式文档。

## 💡 你需要这个 Skill 吗？

如果你想把 `.md` 转成 `.docx`，或希望把已有 `.docx` 按公司模板统一格式，这个 Skill 很适合你。


## 🚫 什么时候不需要？

- 只想原地修改已有 `.docx` 里的几个字（错别字、数值），不涉及换模板或重排样式 → 用 `docx-inplace-edit`。
- 只想查看或编辑 Markdown 内容，不涉及 Word 生成 → 不需要本 Skill。

## 🔗 与其他 Skill 的关系

| 你想做 | 用哪个 |
| --- | --- |
| 把 Markdown / Word 按模板排版生成 `.docx` | **md-to-word** |
| 就地修改已有 `.docx` 中的文字，不换样式 | `docx-inplace-edit` |
## 🎯 它能帮你做什么？

| 你想要 | 它会做 |
| --- | --- |
| Markdown 转 Word | 检查结构、生成 `.docx` |
| Word 只调格式 | 保留内容，统一标题、正文、表格、编号和页面样式 |
| Word 结构整理 | 分析章节、列表、表格结构后重新标准化 |
| Word 换模板 | 把旧 Word 内容迁移到新 Word 模板 |
| 按 Word 模板生成 | 读取模板样式、页眉页脚、页面布局 |
| 正式章节编号 | 使用 Word 真正的自动编号 |
| 表格更好看 | 按内容长度自动分配列宽 |
| 换行和表格编号 | 转换 `<br>` 换行，表格编号项转为 Word 自动编号 |
| 保留原文内容 | 不改写正文、不删业务内容 |

## 🚀 怎么开始？

第一次使用时，请给我一个 Word 模板 `default.docx`。

之后你可以只发文件和一句话，例如：

```text
把这个 Markdown 转成 Word。
```

也可以直接处理已有 Word：

```text
把这个 Word 按标准格式整理一下，不要改内容。
```

## 📦 使用前需要什么？

必需：

- Markdown 文件，或已有 Word 文件。
- `templates/default.docx`。

可选：

- 本次指定模板。
- 明确的字体、字号、页眉页脚等要求。

## 📤 使用后会得到什么？

- 一个 `.docx` 文件。
- Markdown 有结构调整时，会得到对应的 `.standardized.md`。
- Word 结构整理默认只在内部使用中间结构，不会额外生成 Markdown 文件。
- 如有需要你确认的问题，会只列出关键决策点。

## ❓ 常见问题

### 我需要懂 Word 编号设置吗？

不需要。Skill 会分析模板里的编号体系，并让 Word 自己生成章节编号。

### 表格编号和换行会保留吗？

会。表格单元格内的换行会转成 Word 换行；单元格内的编号项会转成 Word 自动编号，并按单元格重新起算。

### Word 内容会被重写吗？

不会。纯样式整理会尽量按原结构处理；结构整理也只调整结构、格式、编号和样式映射，不改业务语义。

### 我上传的 Word 会被保存吗？

不会。只有你明确说保存到模板库时才会保存。
